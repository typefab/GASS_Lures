# Foto dei prodotti

Metti qui le foto delle esche, poi indicale nel pannello di gestione.

1. Salva il file in questa cartella, per esempio
   `public/prodotti/spear-jerk-100-gold-ayu.png`
2. Fai il commit e il push su GitHub (il sito si ricompila da solo)
3. In `/admin/prodotti` apri il prodotto, e nella colorazione corrispondente
   scrivi nel campo **URL foto**: `/prodotti/spear-jerk-100-gold-ayu.png`

Da quel momento il sito mostra la foto al posto dell'illustrazione generata.

Consigli:
- sfondo trasparente (PNG) o bianco, esca in orizzontale con la testa a sinistra
- lato lungo fra 1200 e 1600 px: oltre appesantisce solo il caricamento
- un file per colorazione, con un nome che dica prodotto e colore
